# Contributing to OpenEvolve

First off, thank you for considering contributing to OpenEvolve! It's people like you that make OpenEvolve such a great tool.

## Code of Conduct

This project and everyone participating in it is governed by the OpenEvolve Code of Conduct. By participating, you are expected to uphold this code.

### Pull Requests

The process described here has several goals:
- Maintain OpenEvolve's quality
- Fix bugs and deliver features faster
- Fix problems that are important to users
- Engage the community in working on OpenEvolve
- Enable a sustainable maintainer workflow

## Styleguides

### Git Commit Messages

- Use the present tense ("Add feature" not "Added feature")
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit the first line to 72 characters or less
- Reference issues and pull requests liberally after the first line

### Python Styleguide

All Python code is linted with `ruff`. Please run `ruff check .` before submitting a PR.

### TypeScript Styleguide

All TypeScript code should follow the project's `tsconfig.json` settings and be formatted with `prettier`.
