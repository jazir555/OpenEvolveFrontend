### First-to-Head-by-K Voting

**Algorithm:**
```
1. Spawn N agents (typically N=1000)
2. Each agent votes for solution
3. Count votes for each unique solution
4. Winner = First solution to reach (N/2 + k) votes
5. k is the "margin of victory" (typically k=50)
```

**Properties:**
- Guarantees majority consensus (>50%)
- Additional margin k ensures statistical significance
- Stops early if clear winner (computational efficiency)
- No winner → Red flag (contentious decision)
