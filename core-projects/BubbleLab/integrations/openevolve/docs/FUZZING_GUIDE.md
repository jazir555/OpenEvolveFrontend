## Overview

The Gauntlet fuzzing system automatically tests solutions for vulnerabilities by generating malformed, boundary, and random inputs.

### Benefits

- **Automatic vulnerability detection**
- **Crash reproduction**
- **Vulnerability pattern recognition**
- **Integration with Red Team workflow**

### Quick Start

```python
from bubblelabs_nodes import get_fuzzer

fuzzer = get_fuzzer(max_iterations=1000)

async def solution_func(input_data):
    # Your solution logic
    return process(input_data)

result = await fuzzer.fuzz(
    solution=solution_func,
    input_type='auto',
    constraints={}
)

print(f"Crashes found: {result.crashes_found}")
print(f"Vulnerabilities: {result.vulnerabilities_found}")
```

## Fuzzing Components

### FuzzInputGenerator

Generates test inputs for fuzzing.

```python
from bubblelabs_nodes import FuzzInputGenerator

generator = FuzzInputGenerator()

# Generate different input types
string_input = generator.generate_input('string')
int_input = generator.generate_input('integer', constraints={'min': 0, 'max': 100})
json_input = generator.generate_input('json')
malformed_input = generator.generate_input('malformed')
```

**Input Types:**
- `string`: Random strings
- `integer`: Integers within constraints
- `json`: JSON objects
- `auto`: Automatically determine type
- `malformed`: Malformed inputs for boundary testing

### SolutionFuzzer

Main fuzzing engine.

```python
from bubblelabs_nodes import SolutionFuzzer

fuzzer = SolutionFuzzer(
    max_iterations=1000,
    timeout_seconds=30
)

result = await fuzzer.fuzz(
    solution=your_solution,
    input_type='auto',
    constraints={}
)
```

### CrashDetector

Detects and categorizes crashes.

```python
from bubblelabs_nodes import CrashDetector

detector = CrashDetector()

try:
    your_solution(malicious_input)
except Exception as e:
    crash_info = detector.detect_crash(e)
    print(f"Crash type: {crash_info['crash_type']}")
```

## Input Generation

### Random Input Generation

```python
generator = FuzzInputGenerator(seed=42)

# Generate random strings
for i in range(10):
    random_str = generator.generate_input('string')
    print(f"Input {i}: {random_str[:50]}...")
```

### Boundary Testing

```python
# Test boundary conditions
boundary_inputs = [
    generator.generate_input('integer', constraints={'min': -2**31}),
    generator.generate_input('integer', constraints={'max': 2**31-1}),
    generator.generate_input('string', constraints={'length': 0}),
    generator.generate_input('string', constraints={'length': 1000000}),
]
```

### Malformed Input Generation

## Crash Detection

### Detecting Crashes

```python
detector = CrashDetector()

async def fuzz_solution(input_data):
    try:
        result = solution.process(input_data)
        return result
    except Exception as e:
        crash_info = detector.detect_crash(e)

        print(f"Crash detected!")
        print(f"Type: {crash_info['exception_type']}")
        print(f"Message: {crash_info['exception_message']}")
        print(f"Input: {input_data}")

        return None
```

### Crash Categorization

**Crash Types:**
- `exception`: Standard Python exceptions
- `timeout`: Execution timeout
- `memory_error`: Out of memory
- `system_error`: System-level errors

## Vulnerability Analysis

### CrashAnalyzer

Analyzes crashes to identify vulnerabilities.

```python
from bubblelabs_nodes import get_crash_analyzer

analyzer = get_crash_analyzer()

# Analyze fuzzing results
report = analyzer.analyze(result)

print(f"Vulnerabilities found: {report.vulnerabilities_found}")
print(f"Crash patterns: {len(report.crash_patterns)}")
```

### Vulnerability Categories

1. **Buffer Overflow**: Large input causes overflow
2. **Injection**: Code injection via input
3. **Format String**: Format string vulnerabilities
4. **Null Pointer**: Null dereference
5. **Resource Exhaustion**: Resource limit issues

## Integration with Red Team

### Red Team Fuzzing Workflow

```python
from bubblelabs_nodes import RedTeamFuzzer

red_fuzzer = RedTeamFuzzer()

# Blue Team generates solution
blue_solution = await blue_team.solve(problem)

# Red Team fuzzes the solution
fuzz_result = await red_fuzzer.fuzz_solution(
    solution=blue_solution,
    max_iterations=500
)

# Gold Team reviews vulnerabilities
if fuzz_result.vulnerabilities_found > 0:
    print("⚠️  Vulnerabilities detected!")
    print("Solution rejected by Gold Team")
else:
    print("✅ No vulnerabilities found")
```

## Best Practices

### 1. Start with Auto Detection

```python
# Let fuzzer automatically determine input types
result = await fuzzer.fuzz(
    solution=solution_func,
    input_type='auto',  # Automatic detection
    constraints={}
)
```

### 2. Use Appropriate Iterations

```python
# Development: Fewer iterations
dev_fuzzer = get_fuzzer(max_iterations=100)

# Production: More iterations
prod_fuzzer = get_fuzzer(max_iterations=10000)
```

### 3. Set Reasonable Timeouts

```python
fuzzer = get_fuzzer(
    max_iterations=1000,
    timeout_seconds=30  # Prevents hanging
)
```

### 4. Analyze Results

```python
# Get detailed report
analyzer = get_crash_analyzer()
report = analyzer.analyze(fuzz_result)

# Review crash patterns
for pattern in report.crash_patterns:
    print(f"Pattern: {pattern.description}")
    print(f"Occurrences: {pattern.occurrences}")
    print(f"Severity: {pattern.severity}")
```

### 5. Integrate with CI/CD

```python
# In CI pipeline
async def ci_fuzz_test(solution):
    fuzzer = get_fuzzer(max_iterations=1000)
    result = await fuzzer.fuzz(solution, 'auto', {})

    if result.vulnerabilities_found > 0:
        raise AssertionError("Vulnerabilities detected!")

    return result
```
