# Contributing

Thank you for your interest in contributing to the AI Council Framework.

## How to Contribute

### Reporting Issues
- Open a GitHub Issue describing the problem
- Include which consensus mode you were using
- Note which AI models were involved
- Describe expected vs. actual behavior

### Suggesting Improvements
- Open a GitHub Issue with the "enhancement" label
- Describe the improvement and its expected impact
- If research-backed, include citations

### Submitting Changes
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-improvement`)
3. Make your changes
4. Submit a Pull Request with a clear description

## Areas Where Help Is Especially Valuable

### Benchmarking
We need quantitative comparisons of council outputs vs. single-model outputs across different task types. If you can run controlled experiments and report results, that's extremely valuable.

### Domain-Specific Templates
The framework is domain-agnostic, but domain-specific prompt templates (legal analysis, medical research, financial planning, technical architecture, creative writing) would help users get started faster.

### Automation Tooling
Moving from manual copy-paste orchestration to automated council execution. This could be Python scripts, MCP server implementations, or integrations with existing agent frameworks.

### Multi-Language Support
The framework has been tested primarily in English. Testing and adapting prompt templates for other languages would expand its accessibility.

### Documentation
Clear, practical documentation — especially worked examples of council sessions for different use cases — helps people understand the framework's value.

## Code of Conduct

- Be constructive and respectful
- Back claims with evidence (just like the council protocol)
- Disagree with reasoning, not with people
- The Gemini Principle applies here too: dissent with evidence is welcome

## Questions?

Open an Issue with the "question" label.
