🔬 INTEGRATED APPROACHES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. EVOLVED_POLICIES
     → Evolve rollout policies using genetic algorithms
     → MDAP multi-agent fitness evaluation
     → Best for: General theorem proving

  2. EVOLUTIONARY_NODES
     → Evolve action sequences at each MCTS node
     → Per-node population management
     → Best for: Structured domains (algebra, analysis)

  3. COEVOLUTION
     → Coevolve decision trees with competitive evaluation
     → Host-parasite coevolution
     → Best for: Highly complex theorems

  4. ADAPTIVE
     → Automatically select best approach
     → Problem complexity analysis
     → Best for: Unknown domains

  5. COMBINED
     → Run all approaches in parallel
     → Combine results with MAKER voting
     → Best for: Maximum quality
