009                                               A BSTRACT
010
011            Modern language agents often need to solve long-horizon tasks requiring multiple
012            turns of interactions with the environment, where they retrieve external information,
013            adapt to observations, and answer interdependent queries. Yet, most LLM systems
014            rely on full-context prompting, appending all past turns regardless of their relevance.
015            This leads to unbounded memory growth, increased computational costs, and
016            degraded reasoning performance on out-of-distribution input lengths due to LLM
017            forgetting the context. We introduce MEM1, an end-to-end reinforcement learning
018
               framework that enables agents to operate with nearly near constant context
               size when solving long-horizon tasks. At each turn, MEM1 updates a compact
019
               shared internal state that jointly supports memory consolidation and reasoning.
020
               Leveraging reinforcement learning (RL) and rollout trajectory truncation, we train
021            a MEM1 agent to develop internal states that integrate prior memory with new
022            observations from the environment while strategically discarding irrelevant or
023            redundant information. Experiments across three domains, including internal
024            retrieval QA, open-domain web QA, and multi-turn web shopping, show that
025            MEM1-7B improves performance by 3.5× while reducing memory usage by 3.7×
026            compared to Qwen2.5-14B-Instruct on an augmented multi-hop QA dataset with 16
027            objectives in each task, and generalizes beyond the training horizon. Our results
028            demonstrate the promise of reasoning-driven memory consolidation as a scalable
029
               alternative to existing solutions for training long-horizon task-solving agents with
               multiple interactions, where both efficiency and performance are optimized.

      1   I NTRODUCTION
033
034   Large language models (LLMs) have shown remarkable performance in single-turn tasks such as
035   question answering, summarization, and code generation (Brown et al., 2020; Touvron et al., 2023).
036   However, emerging real-world applications increasingly operate over multiple turns—searching
037   documents, interacting with environments (Zhou et al., 2024), and making decisions based on
038   evolving external information (Wang et al., 2024). Examples include AI search agents such as
039   Perplexity AI (Perplexity AI, 2024) that automate complex tasks by iteratively gathering information,
040   and web-navigation agents such as OpenManus (OpenManus, 2025) and BrowserUse (Müller &
041   Žunič, 2024), which must complete goals across dozens of interactive turns.
042   Unlike traditional tasks where the input is static or self-contained, long-horizon settings often
043   involve answering a sequence of related questions, requiring the agent to continuously retrieve new
044   information, revise beliefs, and adapt to evolving contexts over time. For instance, consider a research
045   assistant tasked with “What’s the evidence for X?”. Subsequent queries like “Who published it?”
046   require further information retrieval, while “Is the source credible?” calls for self-reflection and
047   assessment. Each query builds on the previously collected and accumulated information. Similarly, a
048   shopping assistant may be first asked “Which product is cheapest?”, then “What are its reviews?”,
049   and “Is it compatible with my device?”. These interactions span multiple turns, featuring evolving
050
      contexts and compound reasoning.
051   In long-horizon systems, a common strategy is to append all past observations, actions, and thoughts
052   to the context at each step (Wei et al., 2022; Yao et al., 2023). This creates three challenges. (1)
053   Growing inference cost and memory usage. Transformer-based LLMs scale with O(N 2 ) compute
      (or O(N ) with KV caching) and O(N ) memory as context length N grows (Vaswani et al., 2017),


                                                         1
      Under review as a conference paper at ICLR 2026




054
      forcing deployments to reserve large GPU memory and often wasting resources (Kwon et al., 2023;
055   Zheng et al., 2024). (2) Generalization limits beyond the training horizons. Contexts longer
056   than those seen during training push the model out-of-distribution, reducing its ability to reason
057   reliably (Yoon et al., 2024). (3) Overloaded context and forgetting. Redundant or irrelevant
058   content that grows with agentic interaction dilutes attention and makes the model prone to forgetting
059   important details, even when they remain technically available in the context (An et al., 2025; Liu
060   et al., 2024; Wu et al., 2025).
061   Recent progress in long-context modeling largely targets static inputs (e.g., long documents) and does
062   not address multi-turn interaction with external environments (Beltagy et al., 2020; Gu et al., 2025).
063   Some other approaches introduce external memory modules (e.g., summarizers or retrievers) (Yoon
064   et al., 2024; Li et al., 2023; Chhikara et al., 2025; Xu et al., 2025), but these are typically trained
065   separately and cannot be optimized end-to-end with the agent’s policy. This also introduces additional
066   engineering overhead, as engineers must manage and integrate two separate models. Meanwhile,
067   existing works on tool-using agent systems trained with reinforcement learning leave memory
068   management unsolved, letting the prompt length grow unboundedly (Jin et al., 2025; Zheng et al.,
069
      2025). A natural question is raised: Can a language model learn to consolidate its memory as part
      of its reasoning process so that it retains only what is essential for solving the task?
070
071   Motivated by this question, we present MEM1: Memory-Efficient Mechanism via learning 1-
072   step integrated reasoning and consolidation—a method for training LLM agents that maintain
073   nearly constant memory usage across arbitrarily long horizons. At each turn, the model updates a
074   consolidated state composed of prior memory and newly obtained information. This consolidated
075
      state becomes the agent’s only retained memory, allowing all observations obtained via external tool
      use to be discarded after use, which prevents prompt expansion altogether (illustrated later in Sec. 4.2).
076
      A key insight of our method is that inference-time reasoning (Wei et al., 2022; DeepSeek-AI et al.,
077
      2025; Muennighoff et al., 2025; Yue et al., 2025) serves two purposes: While reasoning about the
078   current query, the model also extracts and stores the essential information it needs for the future.
079   By unifying reasoning and memory consolidation, MEM1 enables the agent to both reason and
080   remember within a shared representational space, without requiring extra modules or architectural
081   changes. We train this behavior end-to-end with reinforcement learning (RL) (Sutton & Barto, 2018;
082   Zhu et al., 2023), optimizing for task success via verifiable rewards (Shao et al., 2024). Although
083   not explicitly optimized for memory efficiency through reward signals, the agent learns to manage
084   memory as part of its policy, resulting in near-constant memory usage across long horizons.
085   We empirically evaluate MEM1 on (1) a multi-turn information retrieval task, where we augment
086   standard single-objective QA datasets into multi-objective settings by composing N multi-hop
087   questions, and (ii) the WebShop environment (Yao et al., 2022), which requires the agent to perform
088   multiple steps of interaction with a textual web environment. Across these diverse settings, MEM1
089   consistently matches or exceeds the performance of leading baselines while achieving efficiency
090   gains of up to 3.5× in memory usage. Moreover, agents trained on our 2-objective augmented tasks
091   generalize robustly to much harder cases with up to 16 sequential objectives. At this extreme, MEM1
092
      not only outperforms all baselines in accuracy but also reduces peak memory usage by 1.27× and
      accelerates inference by 1.78× relative to the strongest uncollapsed baseline.

137   Memory management for LLM agents. A widely adopted approach to memory management
138   in LLM-based agent systems involves appending all prior information, such as observations, inter-
139   mediate thoughts, and actions, into the prompt at each interaction turn (Yao et al., 2023). While
140   this method is straightforward and effective when the number of interactions required is small, it
141   results in unbounded context growth, leading to linearly scaled inference memory. Moreover, long
142   contexts often contain irrelevant or redundant information, which impairs the model’s reasoning
143   capabilities (An et al., 2025; Liu et al., 2024; Wu et al., 2025). To mitigate these issues, recent
144
      studies have proposed external memory frameworks, including retrieval-augmented generation and
      summarization modules (Yoon et al., 2024; Li et al., 2023; Chhikara et al., 2025; Xu et al., 2025) and
145
      hierarchical working memories (Hu et al., 2025b; Rasmussen et al., 2025; Sun & Zeng, 2025). How-
146
      ever, these methods are typically applied independently of the agent’s policy, creating a disconnect
147   between memory and the reasoning process. In addition, managing and integrating such modules
148   often incurs extra computational overhead and system complexity. Despite these advancements, many
149   RL approaches for training LLM agents still rely on accumulating the full interaction history as mem-
150   ory (Jin et al., 2025; Zheng et al., 2025; Qi et al., 2024), leaving memory management during training
151   an underexplored area. In this work, we seek to bridge this gap by tightly integrating memory with
152   the agent’s reasoning process, thereby enabling more efficient and context-aware decision-making.

      3.1   M EMORY AS PART OF R EASONING
176
177   To achieve a constant memory, MEM1 is particularly trained to iteratively refine its understanding
178   by processing new information in conjunction with a consolidation of its prior state. At each turn
179   i, the agent produces a new Si , which summarizes past information and reasons about subsequent
180   actions. Following this, the agent generates an action At —a subsequent query or the answer if a direct
181   response is warranted. If the agent issues a query, the corresponding feedback from the environment
182
      Oi is appended to the trajectory. At the next turn, i + 1, the agent consolidates the tuple (Si , Ai , Oi )
      into a new Si+1 , which serves as the basis for further interactions. After each turn, (Si , Ai , Oi )
183
      is pruned from the context, effectively compressing memory and preventing prompt bloat. Fig. 1
184
      (bottom left) illustrates the evolution of the model’s context over time. At each turn, the agent retains
185   at most two S’s, two A’s, and one O, ensuring bounded and efficient memory usage. The detailed
186   rollout algorithm is in Alg. 1 of App. B.5.
187
188
      RL offers a powerful mechanism for shaping agent behavior through reward signals (Sutton et al.,
      2000). In MEM1, we leverage this framework to incentivize effective state consolidation by designing
189
      environments in which the agent is rewarded only when it strategically retains and integrates useful
190
      information. Specifically, we construct tasks that require numerous interactions with the environment
191   to arrive at a correct answer (see Sec. 3.3). Success depends on the agent’s ability to rely on
192   information collected along the inference path. At each turn, we prune the agent’s context to retain
193   only the most recent internal state S, forcing the agent to perform memory consolidation as part of
194   its reasoning process. Without access to full historical context, the agent must learn to preserve and
195   update relevant knowledge internally in order to reap the reward. This learning procedure mirrors
196   how humans cultivate memorization skills through structured tasks such as Sudoku or crosswords (A
197   Cognitive Connection, 2024), where success hinges on selectively attending to key information and
198   building upon it. Over time, such tasks help individuals develop cognitive strategies that jointly
199
      support efficient memorization and reasoning, similar to our RL method for training MEM1.

201   3.2   M ASKED T RAJECTORY FOR P OLICY O PTIMIZATION
202
      Popular RL algorithms (Schulman et al., 2017; Hu et al., 2025a) update the policy with policy
203
      gradient, which requires the calculation of ∇θ πθ,Q (at , st ). For LLM, πθ,Q (at , st ) is viewed as
204   the logit of the output at of the model, where the input is st . Existing RL frameworks typically
205   compute the ∇θ πθ,Q (at , st )’s for all pairs (at , st ) ∈ τ by passing the entire rollout trajectory τ
206   through the LLM once (i.e., prefilling). However, as MEM1 dynamically consolidates its context,
207   the tokens at do not belong to one single trajectory τ . A naive solution is to break each turn
208   into a sub-trajectory τi = (Si , Ai , Oi ), where i represents the ith interaction turn. However, this
209   approach introduces difficulties (at least implementation-wise) in computing the temporal difference
210   δt = r(st ) + V (st+1 ) − V (st ) for the last token in the current sub-trajectory τi , as V (st+1 ) is
211   calculated in a separate sub-trajectory τj , j ̸= i. Here V : S → R is the value function.
212   To overcome this challenge, we introduce a masked trajectory that compresses {τ1 , τ2 , . . . , τn }
213   for a task with n turns into a consolidated full trajectory τf ull = (τ1 , τ2 , . . . , τn ) =
214   (S1 , A1 , O1 , S2 , A2 , O2 , . . . , Sn , An ). The full trajectory encodes all information needed for ac-
215   curate policy learning while respecting MEM1’s memory consolidation at each turn. Note that
      τf ull is a “stitched“ trajectory where the Si ’s and Ai ’s do not belong to the same roll-out. As

226   3.3   M ULTI -O BJECTIVE TASK D ESIGN
227
228   Although MEM1 is designed to address the tasks involving multi-turn interaction with the external
229
      world, there are limited publicly available datasets that support training for such long-horizon
      interactive processes. Existing benchmarks, such as HotpotQA (Yang et al., 2018), Bamboogle (Press
230
      et al., 2023), and 2wiki (Ho et al., 2020), are often cited as multi-turn benchmarks, yet they typically
231
      involve only two information-seeking steps. Moreover, these datasets are not explicitly structured to
232   support long-horizon interactions that necessitate the agent to manage the memory state.
233
234   To bridge this gap, we introduce a novel task—multi-objective question answering (QA)—that
235
      extends the number of reasoning steps required to solve a problem. Building on existing multi-turn
      datasets such as HotpotQA and Natural Questions (Yang et al., 2018; Kwiatkowski et al., 2019),
236
      we interleave multiple questions from the original QA corpus and construct a single composite
237
      query that requires answering all constituent sub-questions, shown in Prompt 1 of App. B.3. Unlike
238   standard multi-turn QA, this formulation compels the agent to (i) issue multiple search queries, each
239   targeting a distinct sub-question, and (ii) organize the sub-answers into a coherent final response.
240   The augmented dataset inherits the multi-turn retrieval tasks presented in the original HotpotQA.
241   Additionally, to test the agent’s long-horizon processing capability, our multi-objective QA combines
242   multiple multi-turn questions into a grand objective and tasks the agent to answer all the questions
243   combined. For instance, the original HotpotQA dataset contains the following two questions: “Which
244   magazine was started first Arthur’s Magazine or First for Women?” and “The Oberoi family is part of
245   a hotel company that has a head office in what city?”. An augmented task is then: “Answer each of
246
      the following questions: “Which magazine was started first Arthur’s Magazine or First for Women?”
      and “The Oberoi family is part of a hotel company that has a head office in what city?” Organize your
247
      final answer in <answer> and </answer> and separate the answer to each question with semicolon.

250   4     E XPERIMENTS & R ESULTS
251
252   We empirically demonstrate the effectiveness of our approach in training the MEM1 agent to
253   perform multi-turn tasks while preserving a near-constant-sized memory state. We evaluate MEM1
254   against several baselines using a comprehensive set of metrics categorized into accuracy (e.g., Exact
255
      Match, F1 score, Environment Reward) and efficiency (e.g., Peak Token Usage, Dependency Length,
      Inference Time). All MEM1 variants are fine-tuned from the Qwen2.5-7B Base model (Yang et al.,
256
      2024). We use PPO (Schulman et al., 2017) as the RL algorithm as it computes token-level advantages,
257
      bringing stability to the training process. While we also experimented with instruction-tuned and
258   supervised fine-tuned models using curated high-quality trajectories, reinforcement learning from the
259   base model consistently yielded the best performance and generalization.
260
261
      Our experiments are conducted in two standard environments, each reflecting real-world scenarios
      that require multi-turn agent interactions. The first environment is question answering with retrieval-
262
      augmented generation (RAG) (Kwiatkowski et al., 2019; Yang et al., 2018), where the agent must
263
      answer queries by retrieving relevant information from an external knowledge store (either a database
264   or an online search engine). We trained on RAG with a local database (i.e., Wikipedia Corpus)
265   and evaluated on tasks involving open web browsing. For QA, following Sec. 3.3, we construct
266   multi-objective tasks and tested the model performance on tasks with more questions than seen in
267   the training. The second environment is WebShop navigation (Yao et al., 2022), where the agent
268   assists users in online shopping by browsing a website and selecting items based on natural language
269   descriptions. This task requires the agent to iteratively read page content and make navigation
      decisions, following protocols similar to those in WebGPT (Nakano et al., 2022).

      4.4   A NALYSIS ON E MERGENT AGENT B EHAVIORS AND FAILURE C ASES
462
463
464
465   Through analyzing MEM1’s multi-turn interaction traces trained on 2-objective QA, we observe
466
      a range of emergent behaviors that are critical for handling long-horizon, multi-objective tasks,
      demonstrating capabilities well beyond simple retrieval. Additionally, we provide detailed qualitative
467
      and quantitative analysis of cases where MEM1 fails in App. F.2 First, MEM1 learns to manage
468
      multiple questions concurrently by maintaining a structured internal state. As shown in Fig. 3(a),
469   when faced with two multi-turn questions, the agent stores and updates memory for each question
470   separately, guiding subsequent searches based on the identified information gaps. In (b), MEM1
471   exhibits the ability to shift focus when progress on one question stalls, recognizing difficulty and
472   prioritizing the more tractable objective. Meanwhile, MEM1 learns to interleave reasoning and
473   memory in its internal state S’s, weaving important information into its decision-making process
474   to support both information retention and action selection. In Fig. 3 (c), MEM1 explicitly extracts
475   important information from previous search results and leverages it to formulate the next query
476   that best addresses the current information gap. In addition, (d) shows that when new, relevant
477
      information is retrieved, MEM1 explicitly reasons about its significance and selectively updates its
      memory. We believe that learning these interleaved behaviors is key to achieving efficiency gains
478
      in memory without degrading performance. Beyond behaviors unique to our multi-objective setup
479
      and memory architecture, MEM1 also exhibits several general-purpose search strategies. In (e),
480   the agent performs self-verification, correcting an earlier misconception and issuing a new query for
481   confirmation. In (f), complex queries are decomposed into manageable subgoals before initiating
482   the search. In (g), for questions requiring multi-turn information gathering, MEM1 extracts key
483   information from search results and uses it to inform the next search. In (h), when overly specific
484   queries fail, MEM1 re-scopes its query to improve retrieval. Notably, many such behaviors, like
485   verification, making a plan, and iterative search, are also reported in recent studies on deep research
      agents (Jin et al., 2025; Zheng et al., 2025).

      5    C ONCLUSION , L IMITATIONS , AND F UTURE W ORK
487
488
      We introduced MEM1, a reinforcement learning framework that enables language agents to perform
489   long-horizon reasoning with consolidated memory. By integrating inference-time reasoning and
490   memory consolidation into a unified internal state, MEM1 addresses the scalability challenges of
491   prompt growth and achieves competitive performance across QA and web navigation benchmarks,
492   with substantially reduced memory usage and inference latency. Despite these advantages, MEM1
493   assumes access to environments with well-defined and verifiable rewards. However, many open-ended
494   tasks present ambiguous or noisy reward structures. Fully realizing the potential of MEM1 therefore
495   requires advances in modeling such tasks and designing suitable reward mechanisms—challenges
496   that lie beyond the scope of this paper. A promising future direction is to explore methods for training
497
      MEM1 agents in these open-ended settings where reward signals are sparse, delayed, or implicit.

      B.4.1     M ETRICS
949
950   Exact match. In QA tasks, we use exact match (EM) as both the verifiable reward for the RL
951   pipeline and the evaluation metric for the final output. The final response is extracted from between
952   <answer> and </answer>. In multi-objective settings, the response should contain answers to
953   each question separated by semicolons. If the XML tags are mismatched, or if the number of provided
954   answers does not correspond to the number of questions, a score of 0 is assigned. Otherwise, 1 point
955   is credited for each correct answer. During RL training, we do not provide any other intermediate
956   rewards or format penalties, as we find that such manual interventions can interfere with the agent’s
957
      learning process (see more in Sec. 4.4).
958
      F1 score. The F1 score computes the harmonic mean between the precision p and recall r. In the
959
      case of string matching, we split both the predicted answer and the ground truth. For example, if the
960
      ground truth is “United States of America”, it is split into a list with lower-case words: “united”,
961   “states”, “of”, “america”. The same works for the predicted answer. Then, denote the number of
962   common words as c. Further denote the number of words in the predicted answer as l and the number
963   of words in the ground truth as g. Then, precision is calculated as p := c/l and recall is calculated as
964   r := c/g. The F1 score is finally computed as
965
                                                             p×r
966                                             F1 := 2 ×        .
                                                             p+r
967
968   If multiple ground truths are present, the maximum of all F1 scores is chosen. For multi-objective
969   tasks, the final F1 is the sum of the F1 scores for each sub-question.

      GPT-4o-mini tokenizer) in any single sequence throughout the agent’s entire trajectory. For fair

       B.7    A DDITIONAL D ISCUSSION ON THE ATTENTION M ATRIX D ESIGN .
1067
1068   We wish to note that our modification to the attention matrix does not fully recover the attention of
1069   the original trajectories because of the change in position ids. Specifically, prior works (Leviathan
1070   et al., 2023; Chen et al., 2023; Cai et al., 2024) that utilized the attention matrix to compress multiple
1071   trajectories mainly targeted tree-exploration, i.e., generating multiple sequences with the same prefix.
1072   For these works, on top of the attention matrix, they adjusted the position ids as well, so each trajectory
1073   follows a consecutive increasing position ids. However, in MEM1, the prefix does not remain the
1074   same because of memory consolidation. This results in each <IS> having two possible position
1075   ids, one for the previous turn and one for the next turn. To completely recover the original attention,
1076
       we need to duplicate each <IS> and assign different position ids to the two copies. However, such
       duplication can significantly slow down training because the training trajectories are now much
1077
       longer.
1078
1079   As such, for training efficiency, we do not duplicate the <IS> and assign the position ids for

1230   F.2   F ORMAT R EWARD ACCELERATES C ONVERGENCE BUT D EGRADES F INAL P ERFORMANCE

1232   It is common to incorporate format reward when training reasoning models and multi-turn reasoning
1233   agents DeepSeek-AI et al. (2025); Zheng et al. (2025); Jin et al. (2025). In our study, we experimented
1234   with a format reward that enforces the agent to produce outputs using specific structural tags: <IS>,
1235   <query>, and <answer>. If the agent fails to use the expected tags correctly, the turn is terminated
1236   and a penalty of -1 is applied.
1237   As shown in Fig. 6, using the format reward leads to faster convergence during training but results
1238   in worse final performance. The format-constrained agent achieves an exact match score of 0.466,
1239   compared to 0.709 for MEM1 trained with only outcome-based reward on the same testing set for
1240   the 2-objective QA task. Additionally, the format-constrained agent generates fewer tokens, with an
1241   average peak of 514.9 tokens, whereas the outcome-reward-trained MEM1 reaches an average peak
       of 640 tokens.

1243   effective reasoning strategies. As a result, the agent learns to produce shorter responses with valid
1244   syntax but develops less effective internal state representations, leading to degraded task performance.
