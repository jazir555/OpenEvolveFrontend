## Usage Guidelines

### For Developers

1. **Core Systems:** All 9 core systems are production-ready and can be used immediately
2. **Decomposition:** ROMA + MAKER + MDAP + MCTS provide complete problem decomposition
3. **Knowledge:** Use RAGbits for retrieval, Graphiti for temporal KG, pygraphistry for visualization
4. **Verification:** Steer + Evaluator + Adversarial provide comprehensive testing
5. **Mathematics:** Lean 4 + LeanAgent ready for formal verification

### For Integration

1. **New Systems:** Follow the integration architecture in `COMPREHENSIVE_INTEGRATION_ARCHITECTURE.md`
2. **Adapters:** Use MCP protocol for tool integration
3. **Testing:** All integrations must pass E2E tests in `final_integration_test.py`
4. **Documentation:** Create integration guide following existing pattern

### For Operations

1. **Monitoring:** All systems emit structured logs with correlation IDs
2. **Deployment:** Docker/Kubernetes configurations available
3. **Scaling:** Horizontal scaling available for all core systems
4. **Failover:** Circuit breakers and retry logic implemented

### Common Issues

**Issue:** Integration not starting
- **Solution:** Check environment variables, verify dependencies, run probe script

**Issue:** Data format mismatch
- **Solution:** Check canonical schema in `COMPREHENSIVE_INTEGRATION_ARCHITECTURE.md`, verify adapter mapping

**Issue:** Performance degradation
- **Solution:** Check circuit breaker status, enable caching, scale horizontally

**Issue:** Integration test failures
- **Solution:** Verify all dependencies are running, check network connectivity, review logs
