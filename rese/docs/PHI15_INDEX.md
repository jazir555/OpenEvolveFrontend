### For Understanding Φ₁.₅

**What is it?**
- Automated system that detects tacit (hidden) assumptions from null results
- Based on Kuhn's paradigm shift theory
- Part of RESE Phase I (Epistemic Audit)

**How does it work?**
1. Receives null results from Stage 6 (failed attempts)
2. Detects anomalies and clusters similar failures
3. Uses abductive inference to generate candidate explanations
4. Scores confidence using multiple factors
5. Outputs inferred assumptions to Stage 1 (as new constraints)

**Why is it innovative?**
- First automated paradigm shift detection system
- Mines assumptions from failures (not successes)
- Quantitative triggers for paradigm shifts
- Feedback loop to problem reformulation

**What are the targets?**
- >70% assumption mining accuracy (F1 score)
- >60% paradigm shift detection rate
- <10 seconds processing time for 100 failures

## Key Innovations Summary

### 1. Automated Kuhnian Paradigm Shifts
**Traditional**: Paradigm shifts analyzed retrospectively, decades later
**Φ₁.₅**: Real-time detection of accumulating anomalies

### 2. Assumption Mining from Null Results
**Previous**: Mine assumptions from successful cases or requirements
**Φ₁.₅**: Mine assumptions from **failures** (they reveal hidden constraints)

### 3. Multi-Disciplinary Integration
**Combines**: Philosophy of science (Kuhn) + ML (anomaly detection) + Logic (abduction) + Causal inference

### 4. Feedback Loop to Problem Formulation
**Not just detect**: Automatically adds inferred constraints to SCE, enabling problem reformulation
